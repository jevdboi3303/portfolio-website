Personal Project · May 2026 – Present

CoopLens

A Chrome extension that scores UVic co-op postings against your resume in real time, so you know what's worth applying to before you read the whole thing.

Chrome MV3FastAPISupabase PostgresReactLlama 3.3 70B
View code ↗
Problem
Students sift through co-op postings one at a time, with no quick way to judge fit, spot red flags, or see which skills their resume is missing.
Approach
An MV3 extension injects a score panel on each posting. A FastAPI backend has Llama 3.3 70B rate CV match (45%), posting clarity (30%) and company quality (25%), then flags red flags and keyword gaps.
Result
The 90MB embedding model wouldn't fit Railway's free tier, so I replaced it with a 5MB TF-IDF fallback, 95% smaller, which also keeps scoring working when the LLM API is down.

03

Hackathon · 2nd Place · 2025

Web Notes

A Chrome extension that adds a public layer of notes and discussion to any webpage.

Chrome MV3JavaScriptSupabase
View code ↗
Problem
Conversations about a webpage happen somewhere else, so there's no way to leave context on the page itself for the next reader.
Approach
Highlight text to anchor a note to it; a sidebar (Alt+N) shows everyone's notes for that page, backed by Supabase auth and Postgres.
Result
Rendering the sidebar in a Shadow DOM keeps it from clashing with any site's CSS. Placed 2nd at the hackathon.
