CoopLens

A Chrome extension that scores UVic co-op postings against your resume in real time, so you know what's worth applying to before you read the whole thing.

Code ↗
Problem
Students sift through co-op postings one at a time, with no quick way to judge fit, spot red flags, or see which skills their resume is missing.
Approach
An MV3 extension injects a score panel on each posting. A FastAPI backend has Llama 3.3 70B rate CV match (45%), posting clarity (30%) and company quality (25%), then flags red flags and keyword gaps.
Constraint
The 90MB embedding model wouldn't fit Railway's free tier, so I replaced it with a 5MB TF-IDF fallback, 95% smaller, which also keeps scoring working when the LLM API is down.
